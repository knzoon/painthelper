För att kunna använda Painthelper behöver du importera data för de regioner du tagit zoner i. Denna import behöver bara göras en gång, sen kommer Painthelper hålla koll på dina tagningar.

Det går tyvärr inte på ett enkelt sätt göra denna import från en mobiltelefon/platta utan du får gå in på denna sida från en dator. Bilderna i denna hjälp är tagna från Chrome men det kan fungera med andra browsers också.

Själva importen är en tvåstegs-raket som beskrivs nedan.

Skapa fil att importera

  • Logga in på https://turfa.nu/
  • Gå in på sidan "Map of my unique zones"
  • Välj Global i dropdown för att få med alla regioner
  • Högerklicka utanför kartan
  • Välj "Spara som..."

Importera skapad fil

När du gjort det så klickar du på knappen nedan "Importera" och väljer filen du sparade innan.

OBSERVERA att du bör importera en nyligt sparad fil. Alla takes du gör mellan du sparat filen och importerar den kommer att försvinna.
